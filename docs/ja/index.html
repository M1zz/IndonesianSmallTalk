Malmunについて

Malmunは、答え方によって展開が変わる会話で外国語を練習するアプリです。インドネシア語・英語・日本語・中国語・スペイン語・韓国語から学ぶ言語を選べ、アプリの表示も同じ6言語に対応しています。

💬
分岐するスモールトーク
あなたの答えに合わせて会話が進みます。読んでタップしても、声に出して話しても練習できます。
🧳
場面別会話53本
各言語に、基本・日常会話・レストラン・交通・空港・ホテル・買い物・観光・緊急時をそろえています。
🇮🇩
インドネシア語はさらに充実
手作りのスモールトーク、週間時間割つきの1日コース3本、はじめての100単語。
🚗
通勤モード
車でBluetoothやCarPlayにつないで、耳だけで練習。音は車のスピーカーから流れ、文は「再生中」に表示されます。意味を聞き、チャイムのあと自分で言ってみて、答えをゆっくり1回・普通の速さで1回聞きます。CarPlay専用の画面はありません。
🗣️
手を使わずに操作
ハンドルの次へ・前へ・再生ボタンのほか、自分の番に「次」「もう一回」「ゆっくり」「速く」「次の場面」「止めて」と話して操作できます。正しく言えると「いいね！」と返します。Siriや、車につないだときに動くショートカットのオートメーションですぐに始められます。
🎯
練習ツール
スコアつきの発音練習、台本ビュー、貼り付けで会話を取り込み、練習の記録。
📚
マイフレーズと単語カード
覚えた表現をためておき、読み上げつきの単語カードで復習できます。
⌨️
フレーズキーボード
意味を見てワンタップするだけで、学習中の言語の文が入力されます。
👥
友達と一緒に見る
iCloudで友達とシナリオを共有できます。
✨
AIでシナリオ作成
ご自身のAnthropic APIキーを入れてトピックを書くと、新しい会話を作ります。

Malmun Pro

次の2つを除き、すべての機能を無料で使えます。

無料

  • スモールトーク・1日コース・基本単語帳
  • 場面別会話の基本・日常会話
  • 通勤モード（1日3シーンまで）
  • 発音練習・台本ビュー・貼り付け取り込み・練習の記録
  • マイフレーズ・単語カード・フレーズキーボード・友達と共有・AIシナリオ

Malmun Pro

  • すべての場面別会話：レストラン・交通・空港・ホテル・買い物・観光・緊急時
  • 通勤モード無制限

年間サブスクリプションと買い切り（永久）から選べます。価格はアプリ内またはApp Storeでご確認ください。

プライバシー

アカウント登録も広告のためのトラッキングもありません。学習内容は端末と、共有をオンにした場合のご自身のiCloudにだけ保存されます。アプリの改善のために、匿名の利用統計とエラー情報だけを送信します。
