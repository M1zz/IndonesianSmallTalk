개인정보 처리방침

말문 · 시행일: 2026년 10월 19일

말문은 계정을 만들지 않고, 광고나 다른 회사와 나누기 위한 추적을 하지 않습니다. 학습 데이터(표현 · 시나리오 · 응답 · 단어)는 내 기기와 내가 직접 켠 iCloud 에만 저장됩니다.

익명 사용 통계 · 오류 정보

앱을 고치고 더 낫게 만들기 위해 다음 정보를 개발자의 iCloud(CloudKit 공개 데이터베이스)로 보냅니다.

  • 설치할 때마다 무작위로 만드는 식별자
  • 앱 · iOS 버전, 기기 언어
  • 실행 · 사용 횟수, 하루 한 번 앱을 열었다는 기록
  • 앱이 멈추거나 꺼졌을 때의 진단 정보

이름 · Apple 계정 · 학습 내용 · 음성은 보내지 않습니다.

피드백 보내기

설정 ▸ 피드백 보내기로 직접 적어 보낸 내용과, 적은 경우 연락처만 개발자에게 전달됩니다.

구매

말문 Pro 결제와 구독은 Apple 이 처리합니다. 앱은 결제 정보를 받지 않고, 구매했는지 여부만 기기에서 확인합니다.

저장 위치

  • 기기 — 표현 · 시나리오 · 응답은 앱 안의 파일로 저장됩니다.
  • iCloud — '친구와 함께 보기'를 켠 시나리오만 내 Apple 계정의 iCloud(비공개 · 공유 데이터베이스)에 저장됩니다. Apple 의 iCloud 정책을 따릅니다.
  • 앱 그룹 — 키보드와 표현을 나누는 일은 같은 기기 안의 보안 저장소에서만 이뤄지고, 밖으로 보내지 않습니다.

키보드

말문 키보드는 '전체 접근 허용'을 요청하지 않습니다. 키보드로 입력한 글은 지금 쓰고 있는 앱에만 전달되고, 말문이나 어떤 서버로도 보내지 않습니다.

마이크 · 음성 인식

음성으로 연습할 때 마이크와 음성 인식 권한을 요청합니다. 인식은 Apple 의 표준 음성 인식(SFSpeechRecognizer)이 처리하며, 말문은 인식 결과를 답 맞추기에만 쓰고 저장하거나 보내지 않습니다.

퇴근길 모드의 음성 명령은 내가 말해 볼 차례에만 듣고, 들은 말은 기기 안에서만 처리합니다.

AI 로 시나리오 만들기

이 기능을 쓸 때만, 내가 적은 주제와 내가 직접 넣은 API 키로 Anthropic API 에 요청을 보냅니다. 퇴근길 모드를 비롯한 다른 기능은 밖으로 아무것도 보내지 않습니다.
