關於 Malmun

Malmun 讓你透過會分岔的對話，練習真實的會話。選一種要學的語言：印尼語、英語、日語、中文、西班牙語或韓語；App 介面本身也提供同樣這六種語言。

💬
會分岔的閒聊
你怎麼回答，對話就往哪裡走。可以用看的、點的來練習，也可以大聲說出來。
🧳
53 段情境會話
每種語言都有：基本表達、日常閒聊、餐廳、交通、機場、住宿、購物、觀光與緊急狀況。
🇮🇩
印尼語專屬內容
手寫的閒聊情境、三套附每週課表的一日課程，以及 100 個入門單字。
🚗
通勤模式
在車上透過藍牙或 CarPlay，只用耳朵練習。聲音從車上的喇叭播出，句子會顯示在「正在播放」。先聽意思，提示音響起後換你開口說，接著依序播放慢速和正常速度的正確答案。CarPlay 上沒有獨立的 App 畫面。
🗣️
不用動手的操作
可以用方向盤上的下一首、上一首和播放按鍵，也可以在輪到你時開口說：下一個、再一次、慢一點、快一點、下一個場景、停止。說對了會聽到「很棒！」。可以用 Siri 開始，也能透過「捷徑」自動化，在連上車子時自動開始。
🎯
練習工具
附分數的發音練習、腳本檢視、貼上文字匯入對話，以及練習紀錄。
📚
我的常用句與單字卡
儲存你學到的常用句，並用會朗讀單字的單字卡複習。
⌨️
常用句鍵盤
看著意思點一下，就會輸入你正在學的語言的句子。
👥
和朋友分享
透過 iCloud 把情境分享給朋友。
✨
AI 情境
填入你自己的 Anthropic API 金鑰，輸入主題，就能得到一段全新的對話。

隱私權

不用註冊帳號，也沒有廣告追蹤。你的學習內容只會留在你的裝置上，若開啟分享，則會存在 iCloud。App 只會傳送匿名的使用統計和錯誤回報，用來修正問題與改進功能。
