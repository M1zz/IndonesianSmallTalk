앱 소개

"말문" 은 인도네시아어·영어·일본어·중국어·스페인어·한국어 회화를 갈래 있는 대화로 연습하는 앱입니다. (예전 이름: 사노라면) 텍스트·음성 연습, 발음 연습, 차에서 귀로 하는 퇴근길 모드, 친구와 시나리오 공유, 표현 키보드까지 한 곳에 담았습니다. 앱 화면은 한국어·영어·일본어·중국어(간체)·스페인어·인도네시아어로 볼 수 있습니다.

개인정보 처리방침

수집하는 데이터

본 앱은 별도의 사용자 계정을 만들지 않고, 광고나 다른 회사와 공유하기 위한 추적을 하지 않습니다. 학습 데이터(표현·시나리오·응답·단어)는 사용자의 기기와 사용자가 직접 켠 iCloud 컨테이너에만 저장됩니다.

익명 사용 통계 · 오류 정보

앱을 고치고 나아지게 하려고 다음 정보를 개발자의 iCloud(CloudKit 공개 데이터베이스)로 보냅니다: 설치마다 무작위로 만든 식별자, 앱·iOS 버전, 기기 언어, 실행·사용 횟수, 하루 한 번 앱을 열었다는 기록, 앱이 멈추거나 꺼졌을 때의 진단 정보. 이름·Apple ID·학습 내용·음성은 보내지 않습니다.

의견 보내기

설정 ▸ 피드백 보내기로 직접 적어 보낸 내용(과 적은 경우 연락처)만 개발자에게 전달됩니다.

구매

말문 Pro 결제·구독은 Apple 이 처리합니다. 앱은 결제 정보를 받지 않고, 구매했는지 여부만 기기에서 확인합니다.

저장 위치

  • 로컬 — 표현·시나리오·응답은 앱 컨테이너의 JSON 파일에 저장됩니다.
  • iCloud — "친구와 함께 보기" 토글을 켠 시나리오만 사용자의 Apple ID 의 iCloud Private/Shared Database 에 저장됩니다. Apple 의 iCloud 정책을 따릅니다.
  • App Group — 키보드 익스텐션과의 표현 공유는 같은 디바이스 내의 보안 컨테이너에서만 이뤄지며, 외부로 전송되지 않습니다.

외부 전송

키보드 익스텐션은 "전체 접근 허용 (Allow Full Access)" 권한을 요청하지 않습니다. 사용자가 입력하는 텍스트는 호스트 앱에만 전달되고, 본 앱·서버 어디로도 전송되지 않습니다.

마이크 / 음성 인식

음성 모드 사용 시 마이크와 음성 인식 권한을 요청합니다. 인식 처리는 Apple 의 표준 SFSpeechRecognizer 가 담당하며, 본 앱은 인식 결과를 매칭에만 사용하고 저장·전송하지 않습니다.

AI 로 시나리오 만들기

이 기능을 쓸 때만, 사용자가 입력한 주제와 사용자가 직접 넣은 API 키로 Anthropic API 에 요청을 보냅니다. 퇴근길 모드를 비롯한 다른 기능은 외부로 아무것도 보내지 않습니다.

자주 묻는 질문

키보드를 어떻게 추가하나요?
설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가 → "말문 키보드" 선택. 텍스트 입력 중 globe 아이콘으로 전환합니다.
친구가 공유한 시나리오가 안 보여요.
두 사람 모두 iCloud 에 로그인되어 있어야 합니다. 앱을 한 번 종료 후 재실행해서 동기화 트리거를 다시 보내보세요.
키보드에 표시되는 표현 수를 줄일 수 있나요?
홈 화면 우측 하단의 키보드 아이콘 → "키보드 관리" 화면에서 행마다 토글로 끄거나, "전체 끄기" 후 원하는 표현만 다시 켜세요.
발음 매칭이 잘 안 돼요.
음성 인식은 지금 배우는 언어로 동작합니다. 디바이스의 음성 인식 다운로드 상태를 확인해주세요.
무료로 어디까지 쓸 수 있나요? (말문 Pro)
스몰토크·하루 코스·내 표현·단어장·키보드·발음 연습은 모두 무료입니다. 상황별 회화는 기본·일상 대화가 무료이고, 퇴근길 모드는 하루 3장면까지 무료입니다. 말문 Pro(연간 구독 또는 평생 구매)는 상황별 회화 전체와 퇴근길 모드 무제한을 엽니다. 구매·구독 해지·환불은 Apple ID 설정 ▸ 구독에서 할 수 있고, 기기를 바꾸면 Pro 화면의 "구매 복원"을 누르세요.
배우는 언어는 어떻게 바꾸나요?
홈 화면 맨 위 국기를 누르세요. 내 표현·내 시나리오·단어장은 언어마다 따로 저장됩니다.
차에서 어떻게 쓰나요?
폰을 CarPlay 나 블루투스로 연결하고 퇴근길 모드에서 재생을 누르세요. 운전대의 다음/이전 버튼으로 다음 문장·한 번 더를 고를 수 있습니다. "말문 퇴근길 연습 시작" 이라고 Siri 에게 말하거나, 단축어 앱 ▸ 자동화 ▸ CarPlay 연결 시 "퇴근길 연습 시작" 을 걸어 두면 타자마자 시작됩니다. 진행 중에는 딩 소리 뒤 말해 볼 차례에 "다음", "다시", "천천히", "그만" 이라고 말해 조작할 수 있습니다. 이때만 폰 마이크로 듣고, 들은 말은 기기 안에서만 처리합니다.
