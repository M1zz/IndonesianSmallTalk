เกี่ยวกับ Malmun

Malmun ช่วยให้คุณฝึกสนทนาแบบเรื่องจริงผ่านบทสนทนาที่แตกแขนง เลือกภาษาที่อยากเรียนได้ ไม่ว่าจะเป็นอินโดนีเซีย อังกฤษ ญี่ปุ่น จีน สเปน หรือเกาหลี และเลือกใช้หน้าจอแอปเป็นภาษาใดภาษาหนึ่งใน 6 ภาษาเดียวกันนี้ได้ด้วย

💬
สมอลล์ทอล์กที่แตกแขนง
บทสนทนาเดินไปตามคำตอบที่คุณเลือก ฝึกด้วยการอ่านแล้วแตะ หรือพูดออกเสียงก็ได้
🧳
บทสนทนาตามสถานการณ์ 53 บท
มีครบทุกภาษา ทั้งพื้นฐาน คุยเล่นทั่วไป ร้านอาหาร การเดินทาง สนามบิน โรงแรม ช้อปปิ้ง เที่ยวชมสถานที่ และเหตุฉุกเฉิน
🇮🇩
เพิ่มเติมสำหรับภาษาอินโดนีเซีย
สมอลล์ทอล์กที่เขียนขึ้นด้วยมือ คอร์สหนึ่งวัน 3 คอร์สพร้อมตารางประจำสัปดาห์ และคำศัพท์เริ่มต้น 100 คำ
🚗
โหมดเดินทาง
ฝึกด้วยหูในรถผ่านบลูทูธหรือ CarPlay เสียงจะออกลำโพงรถ และประโยคปัจจุบันจะแสดงใน "กำลังเล่น" คุณจะได้ฟังความหมาย เสียงติ๊ง ถึงตาคุณพูด แล้วฟังเฉลยแบบช้าและแบบความเร็วปกติ ทั้งนี้ไม่มีหน้าจอแอปแยกต่างหากบน CarPlay
🗣️
ควบคุมโดยไม่ต้องใช้มือ
ใช้ปุ่มถัดไป ก่อนหน้า และเล่นบนพวงมาลัย หรือพูดในตาของคุณว่า ถัดไป อีกครั้ง ช้าลง เร็วขึ้น ฉากถัดไป หรือหยุด พูดประโยคถูกก็จะได้ยินว่า "เยี่ยม!" เริ่มด้วย Siri หรือให้เริ่มเองด้วยระบบอัตโนมัติในแอปทางลัดเมื่อเชื่อมต่อกับรถ
🎯
เครื่องมือฝึก
ฝึกออกเสียงพร้อมคะแนน มุมมองสคริปต์ นำเข้าบทสนทนาด้วยการวางข้อความ และประวัติการฝึก
📚
วลีของฉันและแฟลชการ์ด
บันทึกวลีที่เจอ และทบทวนคำศัพท์ด้วยแฟลชการ์ดที่อ่านออกเสียงให้ฟัง
⌨️
คีย์บอร์ดวลี
ดูความหมาย แตะครั้งเดียว ประโยคในภาษาที่คุณกำลังเรียนก็ถูกพิมพ์ให้ทันที
👥
แชร์กับเพื่อน
แชร์สถานการณ์ให้เพื่อนผ่าน iCloud
✨
สถานการณ์จาก AI
ใส่คีย์ Anthropic API ของคุณเอง พิมพ์หัวข้อ แล้วรับบทสนทนาใหม่เอี่ยม
