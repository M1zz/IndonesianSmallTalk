关于 Malmun

Malmun 通过会分支的对话帮你练习真实会话。你可以从印尼语、英语、日语、中文、西班牙语、韩语中选择要学的语言，应用界面也支持这六种语言。

💬
分支闲聊
对话会随着你的回答走向不同方向。可以看文字点选，也可以开口说。
🧳
53 个情景对话
每种语言都有：基础、日常闲聊、餐厅、交通、机场、酒店、购物、观光、紧急情况。
🇮🇩
印尼语内容更丰富
手工编写的闲聊、带每周课表的 3 套一日课程，以及入门 100 词。
🚗
通勤模式
在车上通过蓝牙或 CarPlay 连接，只用耳朵练习。声音从车载音响播放，句子显示在“正在播放”中。先听意思，听到提示音后轮到你说，再听一遍慢速和一遍正常速度的答案。没有专门的 CarPlay 应用界面。
🗣️
不用动手也能操作
用方向盘上的下一首、上一首和播放键，或者在轮到你时说“下一句”“再来”“慢一点”“快一点”“下一个场景”“停止”。说对了会听到“很好！”。可以用 Siri 开始，也可以设置快捷指令自动化，一连上车就自动开始。
🎯
练习工具
带评分的发音练习、剧本视图、粘贴导入对话，以及练习记录。
📚
我的表达和单词卡
收藏新学的表达，用会朗读单词的单词卡复习。
⌨️
表达键盘
看着意思点一下，就能输入所学语言的句子。
👥
和朋友一起看
通过 iCloud 和朋友共享情景。
✨
AI 生成情景
填入你自己的 Anthropic API 密钥，输入主题，就能生成新的对话。
